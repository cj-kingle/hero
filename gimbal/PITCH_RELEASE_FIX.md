# Pitch 松杆保持逻辑修正（2026-11-13）

用户反馈：中间位置松杆后向上过冲并严重抖动，上下限位处不抖；重力补偿暂按已调好保留。未取得实机时序数据，因此不能确认物理根因或宣称抖动已经消除。

静态检查发现，原 integrated pitch 松杆后不仅固定目标，还启用接近目标制动包络，并将完整位置 PID 输出分解成位置驱动和剩余制动量，仅对前者保留斜坡状态，随后重新组合。这会使速度环收到的参考偏离完整位置 PID 的决策。上次加入的符号/幅值约束只限制重组结果，仍未移除第二套状态。

本次在 Config 增加 pitch_direct_hold，默认 false（保留旧测试/实验配置），gimbal_config::MakeControl 明确设 true。仅当前 integrated pitch 摇杆为零且非 basic cascade 时生效：

- 保持原积分得到的目标，不在松杆时重新抓取实际位置。
- 外环仍是当前 P/I/D 和测量速度滤波；不启用额外的 stationary arrival 包络。
- 完整位置 PID（包含限位位置反馈）经原速度/行程限制后，直接作为速度环参考，不经位置驱动斜坡和制动量重组。
- 保持阶段同步驱动斜坡状态至当前位置项，以免恢复推杆时使用松杆前的旧状态。
- 保留一个编码分辨率的静止位置误差处理、固定重力支撑、松杆关闭方向摩擦前馈、限位反馈、力矩上限和故障保护；yaw 不改。

新增 PitchDirectHoldPreservesPidThroughRelease 输入回放：双方向运动后松杆、越过目标、反向速度反馈、1～3 ms 调度间隔，检查目标固定、保持参考等于独立位置 PID、重力前馈不变及输出限幅。该回放不代表已验证机械稳定性。

固件使用现有 Debug 工程编译通过。主机测试未执行（此前 WSL 执行未获授权；未安装新工具）。实机仍需观察松杆后的 target/actual angle、pitch target rate、filtered rate、angle D 和 torque。
